# Guía de comandos Git

## ¿Qué es Markdown?

Markdown es un lenguaje de marcado ligero que permite dar formato al texto de forma sencilla mediante símbolos. Se utiliza para crear títulos, resaltar palabras, organizar listas, insertar enlaces y mostrar código, entre otras cosas.

Es muy popular en documentos, archivos README, foros y plataformas como GitHub, y también se puede utilizar en ChatGPT.

## 3 ejemplos de Markdown

### 1\. Texto en negrita y cursiva

**Código Markdown:**

```
**Hola, mundo**
*Hola, mundo*
```

**Resultado:**

**Hola, mundo**

_Hola, mundo_

### 2\. Listas

**Código Markdown:**

```
- Manzana
- Pera
- Naranja
```

**Resultado:**

- Manzana
- Pera
- Naranja

### 3\. Títulos

**Código Markdown:**

```
# Mi título
## Mi subtítulo
```

**Resultado:**

# Mi título

## Mi subtítulo
